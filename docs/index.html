Quickstart

Start with npx.

Use a supported Node.js version, start Drizza from npm on your machine, then open its local address in a browser.

01

Check Node.js

Required version: 22.13+ or 23.4+ (^22.13.0 || >=23.4.0).

02

Start Drizza

Run it from npm, with no clone or build. Data stays in ~/.drizza; --port and --db change the defaults.

npx drizza
03

Open the local app

Default address: http://127.0.0.1:4340/.

Security

Your data stays local.

Drizza runs on loopback. The GitHub integration sends requests directly from the local process to GitHub; token values do not pass through Drizza-hosted services.

Loopback only

The local server binds to 127.0.0.1, not your network interface.

Local database

SQLite data is stored at ~/.drizza/drizza.db.

Tokens out of the database

The SQLite database records only where the GitHub token came from (gh or env), never its value, and the token does not appear in logs, API responses, or the UI. The local MCP token lives in its own file, ~/.drizza/mcp-token, readable only by your user, and is never written to the database.
