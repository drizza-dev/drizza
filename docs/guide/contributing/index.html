Contributing

Get the current Drizza repository running before making a change.

Requirements

Install a supported Node.js version: ^22.13.0 || >=23.4.0. The repository uses npm and includes a lockfile.

Set up the repository

  1. Clone the Drizza repository.
  2. From the repository directory, install dependencies:
npm install

Start the Vite development server:

npm run dev

Before opening a pull request

Build the project to catch compile-time issues:

npm run build

Keep the change focused, describe its user impact, and include the steps you used to verify it. Open a GitHub issue first if the proposed change affects product scope or provider behavior.

Current integration status

GitHub, MCP, and Slack setup details are coming soon. Do not add provider commands or credentials to a contribution until their guides are available.
