Run Drizza locally

Start the local Drizza app and understand how it uses your machine.

Requirements

Use Node.js that matches ^22.13.0 || >=23.4.0. The project uses Node's built-in SQLite support, so use a release in the supported range.

Start Drizza

Drizza is not published to npm yet. Run it from a clone of the repository, with pnpm installed. From the repository directory, install dependencies:

pnpm install

Build the dashboard and the local server:

pnpm build

Start Drizza:

node dist-node/cli/index.js

Drizza binds to 127.0.0.1 and listens on port 4340 by default. Open http://127.0.0.1:4340/ in your browser.

Local data

The SQLite database lives at ~/.drizza/drizza.db. Drizza creates it on the first run and keeps it on your machine.

Back up your data. To preserve local Drizza data, include the database file in your own backup plan. Keep a copy only in a location you trust.

Security and tokens

  • The local server binds to 127.0.0.1, so it is not exposed to other devices on your network.
  • The GitHub integration uses your credentials from the local process and sends requests directly to GitHub. The SQLite database records only where the token came from, never its value. See Connect GitHub.
  • Exact MCP token revocation steps will be published with the MCP guide once its local token location is finalized.

Integrations

To fill the pull request cards, follow Connect GitHub. For agents, see the MCP guide. The Slack integration is coming soon.
