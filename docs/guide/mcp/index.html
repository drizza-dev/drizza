MCP integration

The local MCP integration is not available yet.

Coming soon. The Drizza MCP integration is still being built. There are no endpoint details or agent-registration commands to follow yet.

What this guide will cover

When the integration is ready, this page will explain how to connect supported agents, what the local token can access, and how to rotate or revoke it. The token stays on your machine; the final token-file location and revocation steps will be published with the integration.

Until then

Use the local setup guide for the current installation details. Do not copy configuration snippets from an older Drizza build or another project.
