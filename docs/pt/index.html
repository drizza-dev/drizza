Guia rápido

Comece com o npx.

Use uma versão compatível do Node.js, inicie o Drizza a partir do npm na sua máquina e abra o endereço local no navegador.

01

Confira o Node.js

Versão necessária: 22.13+ ou 23.4+ (^22.13.0 || >=23.4.0).

02

Inicie o Drizza

Rode a partir do npm, sem clone nem build. Os dados ficam em ~/.drizza; --port e --db mudam o padrão.

npx drizza
03

Abra o app local

Endereço padrão: http://127.0.0.1:4340/.

Segurança

Seus dados ficam locais.

O Drizza roda em loopback. A integração com o GitHub envia as requisições direto do processo local ao GitHub; os tokens não passam por serviços hospedados pelo Drizza.

Apenas loopback

O servidor local faz bind em 127.0.0.1, não na interface da rede.

Banco local

Os dados SQLite ficam em ~/.drizza/drizza.db.

Tokens fora do banco

O banco SQLite registra só a origem do token do GitHub (gh ou env), nunca o valor, e o token não aparece nos logs, nas respostas da API nem na interface. O token MCP local fica num arquivo próprio, ~/.drizza/mcp-token, legível só pelo seu usuário, e nunca é gravado no banco.
