Guia rápido

Comece com um comando.

Use uma versão compatível do Node.js, inicie o Drizza na sua máquina e abra o endereço local no navegador.

01

Confira o Node.js

Versão necessária: ^22.13.0 || >=23.4.0.

02

Inicie o Drizza

Execute o pacote no terminal.

npx drizza
03

Abra o app local

Endereço padrão: http://127.0.0.1:4173/.

Segurança

Seus dados ficam locais.

O Drizza roda em loopback. Quando as integrações com provedores estiverem disponíveis, o processo local enviará as requisições diretamente a cada provedor; os tokens não serão enviados a um serviço hospedado pelo Drizza.

Apenas loopback

O servidor local faz bind em 127.0.0.1, não na interface da rede.

Banco local

Os dados SQLite ficam em ~/.drizza/drizza.db.

Instruções de tokens em andamento

A configuração de provedores será publicada em breve. Os tokens não serão gravados no SQLite, nos logs, nas respostas da API ou na interface. Os passos exatos para revogar o token MCP serão publicados quando o local do token for confirmado.
