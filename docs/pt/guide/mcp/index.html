Integração com MCP

A integração local com MCP ainda não está disponível.

Em breve. A integração MCP do Drizza ainda está em desenvolvimento. Ainda não há endpoint nem comandos de registro de agentes para seguir.

O que este guia vai cobrir

Quando a integração estiver pronta, esta página explicará como conectar os agentes compatíveis, quais dados o token local pode acessar e como rotacioná-lo ou revogá-lo. O token fica na sua máquina; o caminho final do arquivo e os passos de revogação serão publicados com a integração.

Enquanto isso

Use o guia para rodar localmente para ver as instruções atuais de instalação. Não copie configurações de uma versão antiga do Drizza nem de outro projeto.
