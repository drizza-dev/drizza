Rodar o Drizza localmente

Inicie o app local do Drizza e entenda como ele usa sua máquina.

Requisitos

Use uma versão do Node.js compatível com ^22.13.0 || >=23.4.0. O projeto usa o suporte nativo a SQLite do Node, então escolha uma versão dentro dessa faixa.

Inicie o Drizza

O Drizza ainda não está publicado no npm. Rode a partir de um clone do repositório, com o pnpm instalado. No diretório do repositório, instale as dependências:

pnpm install

Gere o build do dashboard e do servidor local:

pnpm build

Inicie o Drizza:

node dist-node/cli/index.js

O Drizza faz bind em 127.0.0.1 e usa a porta 4340 por padrão. Abra http://127.0.0.1:4340/ no navegador.

Dados locais

O banco SQLite fica em ~/.drizza/drizza.db. O Drizza o cria na primeira execução e mantém os dados na sua máquina.

Faça backup dos seus dados. Para preservar os dados locais do Drizza, inclua o arquivo do banco no seu plano de backup. Guarde uma cópia apenas em um local confiável.

Segurança e tokens

  • O servidor local faz bind em 127.0.0.1, então outros dispositivos da sua rede não conseguem acessá-lo.
  • A integração com o GitHub usa as suas credenciais a partir do processo local e envia as requisições direto ao GitHub. O banco SQLite registra só a origem do token, nunca o valor. Veja Conectar o GitHub.
  • Os passos exatos para revogar o token MCP serão publicados no guia de MCP quando o local do token for definido.

Integrações

Para preencher os cards de pull requests, siga Conectar o GitHub. Para agentes, veja o guia de MCP. A integração com o Slack será publicada em breve.
