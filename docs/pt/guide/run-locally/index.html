Rodar o Drizza localmente

Inicie o app local do Drizza e entenda como ele usa sua máquina.

Requisitos

Use uma versão do Node.js compatível com ^22.13.0 || >=23.4.0. O projeto usa o suporte nativo a SQLite do Node, então escolha uma versão dentro dessa faixa.

Inicie o Drizza

Execute o pacote no terminal:

npx drizza

O Drizza faz bind em 127.0.0.1 e usa a porta 4340 por padrão. Abra http://127.0.0.1:4340/ no navegador.

Dados locais

O banco SQLite fica em ~/.drizza/drizza.db. O Drizza o cria na primeira execução e mantém os dados na sua máquina.

Faça backup dos seus dados. Para preservar os dados locais do Drizza, inclua o arquivo do banco no seu plano de backup. Guarde uma cópia apenas em um local confiável.

Segurança e tokens

  • O servidor local faz bind em 127.0.0.1, então outros dispositivos da sua rede não conseguem acessá-lo.
  • O comportamento planejado para as integrações com provedores é que o processo local use as credenciais e envie as requisições diretamente a cada provedor. Os tokens não devem passar por serviços hospedados pelo Drizza nem ser gravados no banco SQLite, nos logs, nas respostas da API ou na interface.
  • As integrações com provedores e as instruções de gerenciamento de tokens ainda estão sendo preparadas. Os passos exatos para revogar o token MCP serão publicados no guia de MCP quando o local do token for definido.

Integrações

Os guias de configuração do GitHub, MCP e Slack serão publicados em breve. Este guia ainda não inclui comandos para essas integrações.
