Guia open source

Contribuir

Rode o repositório atual do Drizza antes de fazer uma alteração.

Requisitos

Instale uma versão compatível do Node.js: ^22.13.0 || >=23.4.0. O repositório usa npm e inclui um arquivo de lock.

Configure o repositório

  1. Clone o repositório do Drizza.
  2. No diretório do repositório, instale as dependências:
pnpm install

Inicie o servidor de desenvolvimento do Vite:

pnpm dev

Antes de abrir uma pull request

Compile o projeto para encontrar problemas de compilação:

pnpm build

Mantenha a alteração focada, descreva o impacto para quem usa o produto e inclua os passos usados para verificá-la. Abra uma issue no GitHub primeiro se a proposta mudar o escopo do produto ou o comportamento de um provedor.

Status das integrações

Os detalhes de configuração de GitHub, MCP e Slack serão publicados em breve. Não adicione comandos de provedores nem credenciais a uma contribuição antes da publicação desses guias.
