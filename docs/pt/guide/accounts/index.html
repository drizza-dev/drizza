Guia open source

Contas e dados locais

O app local open source não exige uma conta Drizza.

Uso local do Drizza

Você não precisa de uma conta Drizza para usar o app local open source. O Drizza roda na sua máquina, e o banco SQLite local fica em ~/.drizza/drizza.db.

Contas de provedores

As integrações com GitHub, MCP e Slack ainda não estão disponíveis neste guia. As etapas de conexão, permissões e instruções para revogar tokens serão documentadas quando as integrações correspondentes estiverem prontas.

Não cole credenciais neste guia nem em uma issue. Aguarde as instruções específicas do provedor antes de conectar uma conta.

Privacidade local

O servidor local faz bind em 127.0.0.1. O comportamento planejado para as integrações com provedores é que o processo local use as credenciais diretamente com os provedores, sem gravá-las no banco SQLite nem nos logs do Drizza. Os tokens não devem passar por serviços hospedados pelo Drizza.
