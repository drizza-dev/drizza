Contas e dados locais

O app local open source não exige uma conta Drizza.

Uso local do Drizza

Você não precisa de uma conta Drizza para usar o app local open source. O Drizza roda na sua máquina, e o banco SQLite local fica em ~/.drizza/drizza.db.

Contas de provedores

O GitHub se conecta pelo seu próprio login no GitHub CLI ou por um token de acesso pessoal fine-grained. Nenhuma conta Drizza entra nisso. Veja Conectar o GitHub para os passos, a permissão mínima e como revogar o acesso.

Para agentes, veja o guia de MCP. A integração com o Slack será publicada em breve.

Não cole credenciais neste guia nem em uma issue. Siga as instruções específicas do provedor antes de conectar uma conta.

Privacidade local

O servidor local faz bind em 127.0.0.1. A integração com o GitHub usa as suas credenciais direto com o GitHub, a partir do processo local. O banco SQLite registra só a origem do token, nunca o valor, e o token não é gravado nos logs. Os tokens não passam por serviços hospedados pelo Drizza.
